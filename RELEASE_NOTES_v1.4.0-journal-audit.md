# Release notes — v1.4.0-journal-audit

This release adds the compact refinement-consistency / Born-calibration note and its machine-checked sharpness audit.

## Formalized refinement route

- `AxSplitRC` expresses unchanged-cell consistency for one elementary binary split.
- `Perspective.splitCell` constructs valid binary refinements of one perspective cell.
- `BinaryGenerated` records finite chains of such splits.
- `refinement_binaryGenerated` proves that every finite projective refinement is generated by a finite chain of elementary binary splits.
- `axSplitRC_implies_axRC` upgrades elementary split consistency to finite refinement consistency on the projective perspective domain.
- `axSplitRC_norm_implies_axGrain` derives Grain additivity from elementary split consistency plus normalization.
- `splitRCBornCalibration_projector` connects the refinement route to the existing projector Born-calibration theorem.

## Relative sharpness witnesses

The release also contains four explicit dimension-three witnesses establishing relative necessity of the assumptions, each while retaining the other three:

- `sharpness_remove_norm`: global scale freedom without normalization;
- `sharpness_remove_null`: target-state freedom without projective null support;
- `sharpness_remove_rc`: resolution/context dependence without refinement consistency;
- `sharpness_remove_pos`: a Hermitian trace-one non-positive cross-term witness without positivity.

## Publication-facing audit

`QuantumFoundations/BornRule/RCNote.lean` is the compact facade and `QuantumFoundations/Audit/RCNote.lean` audits the six publication-facing declarations with `#check` and `#print axioms`.

The release was promoted only after both hosted workflows passed on the feature head: integrated Lean build, consolidated axiom audit, downstream API checks, journal audit, source guard, external downstream-consumer tests, and diff hygiene.

No project-specific `axiom`, unresolved `sorry`, or `native_decide` is introduced by this release.

# Quantum Foundations in Lean

A Lean 4 / Mathlib library for finite-dimensional quantum foundations,
machine-checked and free of project-specific mathematical axioms.

## Main formal results

The library contains Wigner's theorem without bijectivity, the one-directional
Uhlhorn--Semrl theorem, projective and effect-perspective Born representation,
refinement coherence generated by elementary binary splits, sharpness
witnesses, finite Naimark dilation, and a strict classification of binary
implementations. Busch's and Gleason's representation theorems are supplied by
the pinned `gleason-theorem-lean` dependency.

## Publication-facing subset

The theorem-centered article using the representation / rigidity / refinement
part of this library is documented in
[PUBLICATION_ARTIFACT.md](PUBLICATION_ARTIFACT.md). A broader preprint,
*A Layered Lean 4 Library for Finite-Dimensional Quantum Foundations with
Typed Premise Auditing*, surveys additional developments outside the scope of
that article.

## Verification

```sh
bash scripts/verify_publication.sh
```

This builds the library, runs
`QuantumFoundations/Audit/PublicationCore.lean`, executes the source guard,
and checks diff hygiene. The headline audit reports only
`propext`, `Classical.choice`, and `Quot.sound`.
